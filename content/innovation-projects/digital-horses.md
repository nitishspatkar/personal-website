3forONE is the first dedicated social media platform for the equestrian industry, uniting horse auctions, thoroughbred racing and professional networking. It aggregates all major international auctions and gallop races in a single calendar with real‑time updates and live streams of events :contentReference. Auction houses feature exclusive profiles and integrated bidding technology, while users can access a comprehensive database of horse profiles, sale histories and performance statistics :contentReference. The platform supports trainers, breeders, jockeys, owners and enthusiasts with networking tools, a jockey exchange service, form points and data analysis for informed betting decisions :contentReference. By combining dynamic data, community interaction and integrated services, 3forONE aims to increase transparency, accessibility and efficiency across the global horse racing and auction markets.

We did a comprehensive usability analysis of the existing 3forONE website—conducting heuristic evaluations, usability tests, analytics reviews, accessibility checks, and navigation audits—to pinpoint key issues in consistency, navigation and mobile access. We did stakeholder workshops, persona development, and low‑fi prototyping to craft EquiApp’s concept solution, featuring real‑time horse search, customizable profiles, AI‑driven pedigree analysis and a proprietary EquiScore. We did the technical implementation of the MVP with a React Native frontend and a Node.js/Express backend (MariaDB / ElasticSearch), delivering fast (<2 s) data loading, modular personalization and initial AI‑analysis modules. We did rigorous software‑quality validation—functionality reviews, expert usability tests, unit tests (>75% coverage), typing enforcement and clean‑code practices—to ensure performance, maintainability and readiness for future AI enhancements.
